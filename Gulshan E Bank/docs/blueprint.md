# **App Name**: Gulshan eBank

## Core Features:

- Authentication: Secure login and signup page (NextAuth)
- Customer Dashboard: Customer dashboard displaying account overview, balance, and recent transactions
- Fund Transfers: Fund transfer interface (same bank)
- Transaction History: Transaction history for all account types (limited to the last 30 days)
- Interest Calculator: A simple interest calculator.
- Chatbot Assistant: AI assistant (tool) that leverages reasoning to help with account and service inquiries. User questions can be typed or submitted via microphone.

## Style Guidelines:

- Primary color: #2E8B57 (Sea Green), evoking trust, security, and growth, appropriate for a financial institution.
- Background color: #808080 (Honeydew), a light and clean background, providing a sense of calm and trustworthiness.
- Accent color: #B8860B (DarkGoldenrod), adding a touch of sophistication and highlighting #808080important elements.
- Body and headline font: 'Inter', a sans-serif font, chosen for its modern, clean, and highly readable style, suitable for both headlines and body text.
- Complex, geometric icons to represent different banking functions.
- Clean and structured layout with clear sections for each functionality, enhancing usability and navigation.
